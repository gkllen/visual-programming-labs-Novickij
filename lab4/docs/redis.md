# Работа с Redis в n8n

**Redis (Remote Dictionary Server)** — это быстрое хранилище данных типа «ключ-значение», работающее в оперативной памяти (in-memory).

## Настройка подключения
Redis запущен в отдельном Docker-контейнере с пробросом порта 6379. Подключение из ноды n8n выполнено по сетевому адресу `host.docker.internal:6379`.

## Реализованные операции в workflows
1. **Set (Запись):** Создан ключ `Novickij` с тестовым текстовым значением. Операция используется для сохранения состояния в кэше.
2. **Get (Чтение):** Успешно извлечено значение по ключу `Novickij`. Нода извлекает строку из памяти Redis и передает её в формате JSON дальше по цепочке.
3. **Delete (Удаление):** Выполнено удаление ключа `Novickij`. Последующая попытка чтения подтвердила, что данные успешно очищены (вернулся пустой результат).

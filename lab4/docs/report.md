## Краткое описание выполненного
В ходе лабораторной работы была успешно развернута среда автоматизации n8n через Docker. Создано несколько рабочих процессов (workflows) для изучения базовых принципов маршрутизации данных, работы с JSON, переменными среды и ветвлением логики. Отдельно был запущен Docker-контейнер с базой данных Redis, настроено сетевое подключение между контейнерами (через `host.docker.internal`) и реализованы операции записи, чтения и удаления ключей из n8n.

## Освоенные ноды
Были изучены и применены на практике следующие ноды n8n:
1. **Manual Trigger (On clicking 'execute')** — ручной запуск рабочего процесса.
2. **Schedule Trigger** — автоматический запуск по заданному расписанию (cron/интервал).
3. **Set (Edit Fields)** — создание и изменение полей данных (включая использование выражений, таких как `{{ $now }}`).
4. **Code (Code in JavaScript)** — написание кастомной логики обработки данных на JS.
5. **If** — условное ветвление процесса на основе значений полей.
6. **HTTP Request** — выполнение GET-запросов к внешним REST API (catfact.ninja).
7. **Redis** — интеграция с in-memory БД (операции Set, Get, Delete).

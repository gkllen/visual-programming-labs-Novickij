## 3. Выводы по работе с Git
В ходе выполнения работы были освоены навыки работы с репозиторием Git и визуальными нотациями. На этапе внесения изменений было наглядно продемонстрировано различие между форматами:
1. Текстовые файлы (`.bpmn`, `.md`) позволяют отслеживать точный diff по строкам.
2. Бинарные файлы (`.png`) не позволяют Git отображать детали изменений, фиксируя лишь факт обновления файла.

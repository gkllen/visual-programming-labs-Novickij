# Описание бизнес-процесса: Аренда автомобиля в каршеринге

**Участники (роли):** Пользователь, Мобильное приложение, Сервер/Система, Автомобиль.

**Шаги процесса:**
1. Пользователь открывает приложение и ищет ближайший автомобиль на карте.
2. Пользователь выбирает автомобиль и нажимает кнопку «Забронировать».
3. Система проверяет баланс карты и наличие активных штрафов.
4. Если есть задолженность, приложение запрашивает погашение; при отказе бронь отменяется.
5. При успешной проверке включается бесплатное время бронирования (15 минут).
6. Пользователь подходит к авто и проводит внешний осмотр на наличие повреждений.
7. Пользователь загружает фото повреждений через приложение (при наличии).
8. Приложение отправляет команду на разблокировку дверей автомобиля.
9. Пользователь садится в авто, запускает двигатель и совершает поездку.
10. Параллельно во время поездки система рассчитывает стоимость и отслеживает GPS-трек.
11. Пользователь паркует авто в разрешённой зоне и завершает аренду в приложении.
12. Система списывает итоговую сумму с привязанной карты и закрывает замки.

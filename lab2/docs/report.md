# Отчет по лабораторной работе №2
## Визуальное программирование и интеграция сервисов в Node-RED

**Студент:** Novickij  
**Окружение:** Docker (Node-RED)  

---

## Цель работы
Изучение базовых концепций событийно-ориентированного программирования, структуры сообщений (`msg.payload`, `msg.topic`), реализация ветвления, сетевых протоколов (HTTP, MQTT), внешних интеграций (Telegram Bot, Dashboard) и локального хранения состояния в Node-RED.

---

## Выполненные задания

1. **2.1 Inject & Debug:** Настроен периодический запуск сообщений каждые 5 с с темой `lab2/Novickij/basic` и вывод полного объекта сообщения (`complete msg object`).
2. **2.2 Function node:** Реализована JS-логика обработки массива оценок с использованием `const`, `let`, цикла `for` и ветвления `if/else`.
3. **2.3 Switch node:** Реализована фильтрация и маршрутизация потока данных по числовым порогам (`>= 8` и `< 8`).
4. **2.4 Change / Set node:** Реализована модификация метаданных сообщения (`msg.topic`, `msg.timestamp`, `msg.payload`).
5. **2.5 Template node:** Сформирован строковый шаблон с использованием движка Mustache.
6. **2.6 HTTP Request:** Выполнен внешний GET-запрос к публичному REST API с парсингом JSON-объекта.
7. **2.7 MQTT in/out:** Организована публикация и подписка на брокер `test.mosquitto.org` по уникальному топику `lab2/Novickij/data`.
8. **2.8 HTTP Endpoints:** Созданы 3 собственных GET-эндпоинта (`/api/text`, `/api/info`, `/api/items`) с обработкой кодов 200 и 400. Описаны в `docs/api.md`.
9. **2.9 Dashboard:** Настроен интерфейс визуализации со шкалой (Gauge) и графиком истории (Chart).
10. **2.10 Telegram bot:** Настроен бот на базе `node-red-contrib-telegrambot` с обработкой команд `/start`, `/status` и эхо-ответом через `otherwise`.
11. **2.11 File Write / Read:** Настроена запись логов в файл `/data/lab2-Novickij.txt` и чтение содержимого.
12. **2.12 Flow Context:** Продемонстрировано сохранение состояния счётчика в контексте потока (`flow.get` / `flow.set`) со сбросом.
